Use the supplied AI automation assignment as the baseline for required workflow, automation, tech stack, testing and submission deliverables.

**Why:** The user emphasized, “It's important you follow the tech stack,” and allowed a deviation when it makes the product better only while still delivering everything the task asks for.

**How to apply:** Distinguish mandatory assignment requirements from permitted implementation choices and optional enhancements. Do not replace missing requirements with extra storefront functionality or claim that old or partial verification establishes full compliance. Audit findings inform the next plan; an audit request alone does not authorize implementing those fixes.
